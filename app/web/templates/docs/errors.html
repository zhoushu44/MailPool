业务状态码与常见错误示例。业务失败时 HTTP 状态仍为 200，请以响应体中的 code 为准。

业务状态码

code说明
00000请求成功
D0001余额不足（预留位，MailPool 无计费体系）
D0002邮箱库存不足（固定号池无未使用过的账号）
D0003项目不存在或已停用
D0004当前无法对此邮箱执行该操作
D0005取件失败 请稍后再试
D0006账号被封禁 取件失败
99999系统异常

API Key 错误

}
