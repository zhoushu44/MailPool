业务状态码与常见错误示例。业务失败时 HTTP 状态仍为 200，请以响应体中的 code 为准。

业务状态码

code说明
00000请求成功
D0001余额不足（计费开启且可用余额不足以冻结单价时返回，不会发货）
D0002邮箱库存不足（固定号池无未使用过的账号）
D0003项目不存在或已停用
D0004当前无法对此邮箱执行该操作
D0005取件失败 请稍后再试
D0006账号被封禁 取件失败
D0007充值 / 支付流程错误（签名校验失败、金额不符、卡密无效等）
99999系统异常

计费说明

计费采用 MailNest 的三段式：取号不扣钱，只冻结；收到验证码才真扣。

阶段触发余额冻结订单状态
holdPOST /api/v1/email/temporary/buy不变+单价pending
chargereceive 拿到验证码-单价-单价charged
releasePOST /api/v1/email/release 或超时（默认 20 分钟）不变-单价free

计费未开启时（默认），全部接口保持免费发放行为，price 返回空串。
