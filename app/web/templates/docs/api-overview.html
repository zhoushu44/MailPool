MailPool 提供 HTTP API，可用于查询项目、取号、接收验证码、释放邮箱以及查询收件记录。

基础说明

请求地址

http://localhost:8000（默认端口，按部署环境替换）

鉴权方式

接口有两套身份，按用途选择：

① API Key（服务端集成 / 第三方调用，取号收码主流程）：在「设置」页生成。

Authorization: Bearer YOUR_API_KEY
curl /api/v1/mails -H "Authorization: Bearer YOUR_API_KEY"

② 登录会话（账户、独占邮箱、客户收件、充值）：网页登录（/app/login）后浏览器持有的 Cookie。

Cookie: mailpool_session=eyJ...
curl /api/app/mailbox/my-emails -H "Cookie: mailpool_session=eyJ..."

各章节已标注需要哪种身份。

响应格式

业务接口统一返回 JSON：

{
    "code": "00000",
    "msg": "",
    "type": "",
    "data": {}
}
字段类型说明
codestring业务状态码，00000 表示请求成功
msgstring错误信息，成功时通常为空
typestring消息类型，成功时为空，出错为 error
dataobject / array / null接口返回数据

状态码说明

状态分为 HTTP 状态码与业务状态码。业务失败时 HTTP 仍为 200，需判断响应体中的 code。

HTTP 状态码说明
200请求已被处理，需继续判断响应体中的 code
401API Key 缺失、错误或已失效

业务状态码详见「错误码」页面。

查询当前可用的项目（邮箱源）列表，无需 API Key。

GET/api/product/info

请求示例

响应示例

    "msg": "",
    "type": "",
    "data": {
        "temporary": [
            {
                "code": "chatgpt001",
                "name": "ChatGPT 注册",
                "query": "",
                "icon": "/static/img/projects/openai.png",
                "stock": null,
                "price": "",
                "original_price": "",
                "sender_domains": "openai.com",
                "mail_keywords": "ChatGPT,openai",
                "duration_seconds": null
            }
        ],
        "exclusive": { "stock": null, "price": "", "original_price": "" }
    }

字段类型说明

mail_keywordsstring邮件关键词过滤（逗号分隔），命中即放行

2. 取号（购买临时邮箱）

按项目取一个邮箱。号池取出本项目没用过的账号。该邮箱立即绑定当前项目，本项目不可再次取用；其他项目不受影响。

POST/api/v1/email/temporary/buy

请求参数

字段类型必填说明
project_codestring是项目编码，可通过 /api/product/info 获取
countnumber否取号数量，默认 1，范围 1-100

请求示例

curl -X POST /api/v1/email/temporary/buy \
    -H "Authorization: Bearer YOUR_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{
        "project_code": "chatgpt001",
        "count": 1
    }'

响应示例

{
    "code": "00000",
    "msg": "",
    "type": "",
    "data": {
        "email": "example@outlook.com",
        "provider": "outlook",
        "project_code": "chatgpt001",
        "project_name": "ChatGPT 注册",
        "account_id": null,
        "status": "holding",
        "acquired_at": "2026-08-15T08:00:00+00:00"
    }
}

3. 接收邮件（取验证码）

轮询指定邮箱，等待目标邮件到达并提取验证码。成功收到后返回邮件验证码。

POST/api/v1/email/receive

请求参数

字段类型必填说明
project_codestring是项目编码
emailstring是已取到的邮箱地址
timeoutnumber否等待秒数，默认取项目配置，范围 10-600
skip_codesarray否需跳过的验证码列表（收到的验证码在其中则继续等待）

请求示例

curl -X POST /api/v1/email/receive \
    -H "Authorization: Bearer YOUR_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{
        "project_code": "chatgpt001",
        "email": "example@outlook.com",
        "timeout": 120
    }'

响应示例（成功）

{
    "code": "00000",
    "msg": "",
    "type": "",
    "data": {
        "email": "example@outlook.com",
        "code": "123456",
        "status": "success",
        "elapsed": 8.5
    }
}

响应示例（超时）

超时属正常轮询结果，code 仍为 00000，可通过 status 判断：

{
    "code": "00000",
    "msg": "",
    "type": "",
    "data": {
        "email": "example@outlook.com",
        "code": "",
        "status": "timeout",
        "elapsed": 120.0,
        "message": "等待 120s 未收到验证码"
    }
}

8. 账户注册与登录（邮箱验证码）

面向网页客户的账户体系。注册时向邮箱发送 6 位纯数字验证码（10 分钟内有效，错误 5 次作废，校验成功立即失效）。除特别说明外无需 API Key。

GET/api/v1/auth/config

查询登录注册策略（是否开放注册、是否强制邮箱验证、是否支持邮箱验证码登录）。前端按此决定显示哪些登录方式。

curl /api/v1/auth/config
{
    "code": "00000",
    "data": {
        "allow_register": true,
        "allow_password_login": true,
        "require_email_verify": true,
        "email_login_enabled": true
    }
}
POST/api/v1/auth/send-code

发送验证码到指定邮箱。限流：同一邮箱 60 秒冷却、每小时最多 5 封；同一 IP 每小时最多 20 封。

curl -X POST /api/v1/auth/send-code \
    -H "Content-Type: application/json" \
    -d '{ "email": "you@example.com", "purpose": "register" }'
{
    "code": "00000",
    "data": { "sent": true, "ttl_minutes": 10, "message": "验证码已发送，请查收邮件" }
}
字段类型必填说明
emailstring是接收验证码的邮箱
purposestring否register（默认，注册）/ reset（登录、换绑）
POST/api/v1/auth/register

注册账户。用户名 3-32 位（字母数字 _-.），密码 8-128 位；开启邮箱验证时必须带有效验证码。

curl -X POST /api/v1/auth/register \
    -H "Content-Type: application/json" \
    -d '{
        "username": "alice",
        "email": "you@example.com",
        "password": "your-password",
        "code": "765948"
    }'
{
    "code": "00000",
    "data": { "id": 5, "username": "alice", "email": "you@example.com", "email_verified": true }
}
POST/api/v1/auth/login-code

邮箱验证码登录（免密码）。purpose 用 reset 的验证码。成功返回会话 token，可直接当 Cookie mailpool_session 使用。

curl -X POST /api/v1/auth/login-code \
    -H "Content-Type: application/json" \
    -d '{ "email": "you@example.com", "code": "765948" }'
{
    "code": "00000",
    "data": { "user_id": 5, "username": "alice", "session": "eyJ..." }
}
GET/api/v1/auth/me

查询当前登录客户的信息。需要登录会话（Cookie mailpool_session）。

curl /api/v1/auth/me -H "Cookie: mailpool_session=eyJ..."
{
    "code": "00000",
    "data": {
        "id": 5, "username": "alice",
        "email": "you@example.com", "email_verified": true,
        "balance": "10.000", "available_balance": "10.000"
    }
}
POST/api/v1/auth/rebind-email

换绑邮箱，需要新邮箱的有效验证码（purpose=reset）。需要登录会话。

9. 独占邮箱

买断一个邮箱长期持有：购买后该邮箱只属于你，不会被分配给其他用户，不限项目、不限时长，可反复收件，也可主动释放回池。

除库存查询外，以下接口均需登录会话（Cookie mailpool_session）。与 API Key（服务端集成）是两套身份。

GET/api/app/exclusive/stock

查询可售的独占邮箱数量。无需登录。

curl /api/app/exclusive/stock
{ "code": "00000", "data": { "available": 35 } }
POST/api/app/exclusive/buy

购买独占邮箱。开启计费且配置了单价时一次性扣费（买断式，付钱即得）。

curl -X POST /api/app/exclusive/buy \
    -H "Cookie: mailpool_session=eyJ..." \
    -H "Content-Type: application/json" \
    -d '{ "count": 1 }'
{
    "code": "00000",
    "data": [
        { "id": 3, "email": "jackie@outlook.com", "status": "active", "price": "30.000" }
    ]
}
GET/api/app/exclusive/list

列出我持有的独占邮箱（仅 active）。

curl /api/app/exclusive/list -H "Cookie: mailpool_session=eyJ..."
{
    "code": "00000",
    "data": { "total": 1, "items": [ { "id": 3, "email": "jackie@outlook.com", "status": "active" } ] }
}
POST/api/app/exclusive/release

释放独占邮箱回公共池。释放后其他用户可能买到，操作前请确认不再需要。

curl -X POST /api/app/exclusive/release \
    -H "Cookie: mailpool_session=eyJ..." \
    -H "Content-Type: application/json" \
    -d '{ "email": "jackie@outlook.com" }'
{ "code": "00000", "data": { "email": "jackie@outlook.com", "released": true } }

完整示例（Python）

使用 MailPool 提供的邮箱完成注册收码全流程：

from time import sleep

import requests

BASE_URL = "http://localhost:8000"
API_KEY = "YOUR_API_KEY"
PROJECT_CODE = "chatgpt001"

HEADERS = {"Authorization": f"Bearer {API_KEY}"}


def get_product_info():
    """查询项目信息（无需 API Key）"""
    resp = requests.get(f"{BASE_URL}/api/product/info", timeout=30)
    return resp.json()["data"]


def buy_email():
    """取号"""
    resp = requests.post(
        f"{BASE_URL}/api/v1/email/temporary/buy",
        headers=HEADERS,
        json={"project_code": PROJECT_CODE},
        timeout=30,
    )
    data = resp.json()
    assert data["code"] == "00000", data
    return data["data"]["email"]


def receive_code(email: str, timeout: int = 120):
    """等待验证码"""
    resp = requests.post(
        f"{BASE_URL}/api/v1/email/receive",
        headers=HEADERS,
        json={"project_code": PROJECT_CODE, "email": email, "timeout": timeout},
        timeout=timeout + 10,
    )
    data = resp.json()
    assert data["code"] == "00000", data
    return data["data"]


def release_email(email: str):
    """释放邮箱"""
    resp = requests.post(
        f"{BASE_URL}/api/v1/email/release",
        headers=HEADERS,
        json={"project_code": PROJECT_CODE, "email": email},
        timeout=30,
    )
    data = resp.json()
    assert data["code"] == "00000", data


if __name__ == "__main__":
    # 1. 取号
    email = buy_email()
    print(f"取到邮箱: {email}")

    # 2. 轮询等验证码（最多等 120s）
    result = receive_code(email, timeout=120)
    if result["status"] == "success":
        print(f"验证码: {result['code']}（耗时 {result['elapsed']}s）")
    else:
        print("超时未收到验证码")

    # 3. 释放
    release_email(email)
