按项目取号、收验证码的短期邮箱，用完即释放，支持批量获取。

工作原理

MailPool 的「临时邮箱」不是固定邮箱，而是按项目产出的一次性地址：

  1. 调用取号接口，按 project_code 路由到对应邮箱源
  2. 临时源（MailNest / CF / TempMail）直接生成新地址；固定号池（Outlook）从池中取一个未用过的账号
  3. 该地址立即绑定到当前项目——被任何项目用过的邮箱，其他项目（含原项目）都不会再拿到
  4. 轮询取码接口直到收到验证码（或超时）
  5. 释放后临时地址销毁 / 池号归还

邮箱源类型

邮箱源类型特点
MailNest 临时邮箱临时调用迈巢平台购买，支持发件域名 / 关键词匹配
CF 临时邮箱临时Cloudflare 临时域名，秒级生成
TempMail.lol临时公共临时邮箱接口
Outlook 号池固定自备账号导入池中，轮换使用，账号被封自动标记

验证码提取

每个项目可配置提取正则，系统在收件时自动从邮件正文匹配验证码；也支持配置发件域名 / 邮件关键词来过滤目标邮件，命中任意一组即放行返回。

批量取号

取号接口支持 count 参数（1-100），批量返回数组：

POST /api/v1/email/temporary/buy
{ "project_code": "chatgpt001", "count": 5 }
{
    "code": "00000",
    "data": [
        { "email": "a@tempmail.lol", "status": "holding" },
        { "email": "b@tempmail.lol", "status": "holding" },
        ...
    ]
}
