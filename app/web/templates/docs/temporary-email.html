按项目取号、收验证码的邮箱，用完即释放，支持批量获取。

工作原理

MailPool 的邮箱来自私有 Outlook 号池：

  1. 调用取号接口，按 project_code 路由到号池
  2. 从池中取一个本项目没再用过的可用账号
  3. 该地址立即绑定到当前项目——本项目用过的邮箱不会再拿到；其他项目不受影响，照常可取
  4. 轮询取码接口直到收到验证码（或超时）
  5. 释放后账号归还号池，供其他项目继续使用

邮箱源类型

邮箱源类型特点
Outlook 号池固定自备账号导入池中，轮换使用，账号被封自动标记

验证码提取

每个项目可配置提取正则，系统在收件时自动从邮件正文匹配验证码；也支持配置发件域名 / 邮件关键词来过滤目标邮件，命中任意一组即放行返回。

批量取号

取号接口支持 count 参数（1-100），批量返回数组：

POST /api/v1/email/temporary/buy
{ "project_code": "chatgpt001", "count": 5 }
{
    "code": "00000",
    "data": [
        { "email": "a@outlook.com", "status": "holding" },
        { "email": "b@outlook.com", "status": "holding" },
        ...
    ]
}
