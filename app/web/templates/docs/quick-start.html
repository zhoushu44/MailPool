五分钟上手：创建项目 → 配置邮箱源 → 调用 API 取号、取码。

1. 创建项目

在控制台「项目」页面新建项目：

  1. 填写项目编码（调用 API 时传入，如 chatgpt001）与项目名称
  2. 选择邮箱源：MailNest 临时邮箱 / CF 临时邮箱 / TempMail / Outlook 号池
  3. 配置验证码提取正则与发件匹配规则（发件域名 / 邮件关键词，命中任意一组即放行）
  4. 保存后项目即为启用状态

2. 配置邮箱源

在「设置」页面对每个邮箱源填入账号密钥；固定号池（Outlook）还需要在「邮箱池」导入账号。

3. 调用 API

核心流程三步：取号 → 等码 → 释放。

先在设置页生成 API Key，请求头携带 Authorization: Bearer <API_KEY>。

POST /api/v1/email/temporary/buy
{
    "project_code": "chatgpt001"
}
{
    "code": "00000",
    "msg": "",
    "type": "",
    "data": {
        "email": "xxx@tempmail.lol",
        "project_code": "chatgpt001",
        "project_name": "ChatGPT 注册",
        "status": "holding"
    }
}

4. 等待验证码

POST /api/v1/email/receive
{
    "project_code": "chatgpt001",
    "email": "xxx@tempmail.lol",
    "timeout": 120
}
{
    "code": "00000",
    "data": { "email": "xxx@tempmail.lol", "code": "123456", "status": "success", "elapsed": 8.5 }
}

收到目标邮件后，系统按项目的正则规则自动提取 code；超时则 status 为 timeout。

5. 释放邮箱

POST /api/v1/email/release
{
    "project_code": "chatgpt001",
    "email": "xxx@tempmail.lol"
}

临时邮箱释放后销毁；固定号池账号回池。已使用过的邮箱不会被任何项目再次取到（防复用）。

完整示例（Python）

import requests

BASE_URL = "http://localhost:8000"
API_KEY = "你的 API Key"

def buy(project_code: str) -> str:
    resp = requests.post(
        f"{BASE_URL}/api/v1/email/temporary/buy",
        headers={"Authorization": f"Bearer {API_KEY}"},
        json={"project_code": project_code},
        timeout=30,
    )
    data = resp.json()
    assert data["code"] == "00000", data
    return data["data"]["email"]

def wait_code(project_code: str, email: str, timeout: int = 120) -> str:
    resp = requests.post(
        f"{BASE_URL}/api/v1/email/receive",
        headers={"Authorization": f"Bearer {API_KEY}"},
        json={"project_code": project_code, "email": email, "timeout": timeout},
        timeout=timeout + 10,
    )
    data = resp.json()
    assert data["code"] == "00000", data
    return data["data"]["code"]
